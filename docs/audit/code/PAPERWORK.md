# Release paperwork recheck (licences, credits, store copy, metadata)

Branch `audit/code` at `96965c7`. Read-only: nothing in the game, desktop shell or docs was changed. Every finding was checked against files or command output. Severity: **BLOCKER** = would fail Steam review, a legal problem, or a significant false store claim; **MAJOR**; **MINOR**. Confidence: **CONFIRMED** (read in the files or reproduced by a command), **LIKELY**, **SUSPECTED**.

Method for the package contents: the `game` filter from `desktop/electron-builder.config.js:13-16` (default build, `HT_FULL_ASSETS` unset) was applied with `minimatch` to every file in the repo, in order, with `!` patterns excluding. Result: **565 files, 70.3 MB** under `resources/game`, plus `THIRD-PARTY-NOTICES.txt` (extraFiles) and the asar (main.js, preload.js, save-store.js, steam.js, package.json, build/icon.png, plus the production npm deps `steamworks.js`, `@types/node`, `undici-types`).

## Findings

### P-1 · BLOCKER · The generative-AI disclosure says the rest of the game is "hand-written". The git history says otherwise · CONFIRMED (history), judgment on Valve wording

- `docs/steam/STORE.md:145`, the text to paste into the content survey: "Everything else in the game is hand-written code, procedural art and sound generated by that code, or credited CC0/MIT assets made by people."
- `git log --format='%an' | sort | uniq -c` on this branch: all 465 commits carry an AI coding assistant's author identity. `git log --format='%b' | grep -ci co-authored-by` gives 308 AI co-author trailers. Across all refs, 471 of 472 commits have that identity. So the shipped code was written with AI tools, and so was every player-facing string: dialogue and briefs in `index.html` and `js/jobs/*.js`, item names and blurbs in `js/save.js`, and the procedural art and music code.
- `STORE.md:141` quotes Valve's definition: Pre-Generated content is "Any kind of content that ships with your game and is consumed by players" that was "created with the help of AI tools during development". Dialogue and in-game text are consumed by players. `CONTENT.md:102` already said "Also declare any AI-assisted code or text if the owner's policy says so", but `CHECKLIST.md:21` (A8) marks the AI section "decided" with the narrower text.
- Why it matters: submitting a survey answer that is factually untrue ("hand-written") is a store-review and misrepresentation risk. Fix: change the text so it covers AI-assisted code, writing and procedural content as well as the 7 Pixel Art Atlas models, and remove the word "hand-written".

### P-3 · MAJOR · The third-party notices leave out the runtime and the Steam layer · CONFIRMED (docs), LIKELY (what actually ends up on disk)

- `assets/credits/THIRD-PARTY-NOTICES.txt` (shipped at the install root, `electron-builder.config.js:22`) covers Rocketbox, three.js, meshoptimizer and the fonts (lines 5-84). The LICENCES.md "Libraries" table (`LICENCES.md:45-55`) has no row for:

  - **Valve's Steamworks redistributables** inside it (`dist/win64/steam_api64.dll`, `dist/linux64/libsteam_api.so`, `dist/osx/libsteam_api.dylib`, from the `npm pack steamworks.js@0.4.0 --dry-run` listing)

- Fix: add rows to LICENCES.md and sections to THIRD-PARTY-NOTICES.txt for Electron/Chromium (or point to the two files electron-builder ships), steamworks.js (MIT, its copyright line) and the Steamworks SDK redistributables. ### P-8 · MINOR · A 3.4 MB orphan duplicate ships, plus some dead weight · CONFIRMED
