# Menus (js/save.js, css/menus.css)

No new asset files. What the menus use:

| What | Source | License |
|---|---|---|
| Item icons, logos, vehicle and gun vector thumbnails | Drawn in code (`js/save.js`, ICONS section) for this project | Same as the repository |
| 3D thumbnails | Rendered at runtime from models already in `assets/` (see `assets/CREDITS.md`: Poly Haven, Kenney, Quaternius and others, all CC0) | CC0 |
| Fonts: Bowlby One, Barlow, Barlow Condensed | Google Fonts | SIL Open Font License 1.1 |
| UI sounds | Synthesized at runtime (`HT.Audio.ui` from `js/audio.js`, or the small fallback synth in `js/save.js`) | No samples |
| Horn tunes | Note data in `js/carai.js` (`HT.Garage.HORNS`); public-domain compositions (Beethoven 1824 and 1810/1867, Rossini 1829, Joplin 1902, von Tilzer/Norworth 1908, "Shave and a Haircut" 1899), synthesized, no recordings | Public domain |
